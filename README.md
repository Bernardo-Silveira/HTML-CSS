# Test of HTML and CSS

A simple project created to practice the fundamentals of HTML and CSS.

The project consists of a basic web page where I experimented with HTML structure and different CSS styling techniques.

## About the Project

This project was created as part of my learning process in web development.

The main goal was to practice creating a page from scratch and understand how HTML and CSS work together to build and style a website.

## Technologies

* HTML5
* CSS3
* Git
* GitHub

## What I Practiced

Throughout this project, I practiced:

* Creating the basic structure of an HTML page
* Using HTML elements to organize content
* Styling elements with CSS
* Working with colors and fonts
* Adding borders and rounded corners
* Using background images
* Creating links to external websites
* Organizing files and folders
* Using Git and GitHub for version control

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Bernardo-Silveira/HTML-CSS.git
```

2. Navigate to the project folder:

```bash
cd HTML-CSS
```

3. Open the following file in your browser:

```text
src/HTML/index.html
```

No additional setup or dependencies are required to view the page.
